# 🎓 Student Bio-Data Python Project

A beginner-friendly Python project that collects personal, educational, and interest-based information from the user and displays it in a clean, friendly bio-data format.

This project is ideal for:
- Python beginners
- College mini projects
- Practice with input/output, variables, and f-strings

---

## 🚀 Features

- Asks **10+ user questions**
- Covers:
  - Personal details
  - Education (10th, 12th, B.Tech)
  - Interests & favorites
- Uses:
  - `input()`
  - Variables
  - `print()`
  - f-strings
- Clean and formatted output
- Beginner-friendly code with comments

---

## 🧠 Questions Asked

1. Name  
2. Age  
3. Place of birth  
4. Current city  
5. 10th class school  
6. 10th board  
7. 12th class school  
8. 12th stream  
9. B.Tech college  
10. B.Tech domain  
11. Favorite sport  
12. Favorite personality  
13. Hobby
